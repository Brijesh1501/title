Highlight Latest Rows

Upload a CSV with a Website column and it groups every row by website, finds the most recent one in each group, and highlights it — the same logic as the highlightLatestByCreatedDate() and highlightLatestCampaign() spreadsheet macros, combined into one tool with the date source and date format chosen at run time instead of hardcoded.

Only used to disambiguate three-number dates (e.g. "05/06/2024"). A date already written as YYYY-MM-DD is read correctly either way.

Reads the month name and the fiscal-year pair (e.g. "FY 25-26") out of the campaign name text, same as the original macro.
