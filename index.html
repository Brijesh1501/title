Clean up a roster in six passes.

Six focused tools for prepping contact lists before they land in a CRM or outreach sequence: sort every job title into a department, level and function; rewrite every US phone number into one consistent format; turn a raw report export into a ready-to-import contact sheet; flag the most recent entry per website; fill in any missing State, Country, Region or Timezone from a lookup table; and flag domain mismatches and duplicate emails.

Rules engine · lives in Supabase

Job Title Categorizer

Paste or upload a list of job titles. Each one is matched against a keyword taxonomy for responsibility area, seniority level and department function — the same logic as the original spreadsheet macro, now editable by an admin without touching code.

Open the categorizer Runs entirely in your browser

Phone Number Formatter

Paste text or upload a CSV with "Mobile No." / "Direct No." columns. Every recognizable US number — (408) 368-1105, +12129280800, 1-860-558-5857 — is rewritten as +1 408-368-1105.

Report → Contact Sync

Upload a report export and it's rewritten into a clean contact sheet using a field mapping stored in Supabase — the same logic as the original syncReportToContactSheet() spreadsheet macro, now editable by an admin without touching code.

Highlight Latest Rows

Upload a CSV and it groups rows by Website, finds the most recent one in each group — by Created Date or by parsing the Campaign Name — and highlights it, the same logic as the original highlightLatestByCreatedDate() and highlightLatestCampaign() macros.

Open the highlighter Lookup table · lives in Supabase

Fill Missing Location Data

Upload a contact sheet and any blank State, Country, Region or Timezone cell is filled in by matching against a lookup table — the same logic as the original fillMissingLocationData() spreadsheet macro, now with the lookup table editable by an admin instead of a second spreadsheet tab.

Data Quality Checks

Upload a CSV and flag rows where the email domain doesn't match the company website, and rows with a duplicate email address elsewhere in the file. Port of matchWebsiteAndEmailDomain() and markDuplicateEmails().
