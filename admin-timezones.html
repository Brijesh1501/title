Manage timezone lookup

Each row is one City/State/Country reference the location-fill tool can match against. This replaces the hardcoded "TimeZone" reference sheet from the original Apps Script — add, edit or remove an entry here, no redeploy required. City is optional; State and Country matching work without it.

Adds rows with headers City, State, Country, Region, Timezone (any casing). Existing City/State/Country combinations are skipped, not overwritten.
